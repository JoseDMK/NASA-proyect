\# NASA - Sistema de Gestión Espacial



Aplicación web desarrollada en \*\*C# con ASP.NET MVC\*\* y \*\*Entity Framework\*\* para la gestión y administración de misiones, naves y experimentos espaciales.



\---



\## Características principales



\- \*\*Gestión de Misiones:\*\* Registro, consulta, edición y seguimiento de misiones espaciales.

\- \*\*Gestión de Naves:\*\* Administración del catálogo de naves asignadas a operaciones.

\- \*\*Gestión de Experimentos:\*\* Control de experimentos vinculados a las misiones.

\- \*\*Persistencia de datos:\*\* Modelado relacional y migraciones gestionadas con Entity Framework.

\- \*\*Interfaz responsiva:\*\* Vistas Razor estilizadas con Bootstrap.



\---



\## Tecnologías utilizadas



\- \*\*Lenguaje:\*\* C#

\- \*\*Framework:\*\* .NET / ASP.NET Core MVC

\- \*\*ORM:\*\* Entity Framework

\- \*\*Frontend:\*\* Razor Views, HTML5, CSS3, Bootstrap

\- \*\*IDE:\*\* Visual Studio



\---



\## Requisitos previos



\- \[.NET SDK](https://dotnet.microsoft.com/download) instalado.

\- SQL Server (LocalDB o instancia local) configurado.

\- Visual Studio 2022 o superior (opcional, también puede ejecutarse por consola).
